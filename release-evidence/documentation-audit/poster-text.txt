Research Contribution
A deterministic, non-executing IAM linter specialized for AI-agent roles with 25 product rule IDs (24 static plus
one live-context boundary-presence rule) spanning identity/trust patterns and role context, emitting text, JSON,
and SARIF for pre-deployment review and CI gating.

Method and Control Path
01
Parse one IAM policy document without executing cloud actions.
02
Classify statements and trust-policy structure.
03
Apply deterministic rule checks for privilege escalation, excessive privilege, trust
weaknesses, audit tampering, and missing boundaries.
04
Emit findings with stable rule IDs and severity.
05
Return CI-friendly exit codes and optional SARIF.
Limitations and Residual Risk
Performance values are CI microbenchmarks on synthetic policies, not
production SLOs.
The tool is a static analyzer, not a runtime authorization proxy.
It does not prove account-wide effective permissions or every cross-resource
escalation path.
The 3 skipped tests are legacy rules-module API tests (rules module not
importable), as recorded in the cited source; they are not live-AWS checks.
